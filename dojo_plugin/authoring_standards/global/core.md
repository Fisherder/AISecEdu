# 全局出题规范 v1.0.0

适用于所有课程和题型。先确认真实课程、题型、学习目标、前置知识、学生交付方式和可用环境，再开始生成。题型来自教师意图和结构化任务，不凭课程名称猜测。

1. 每题有稳定标识、清楚标题、可观察的学习目标、学生需要做的事和明确的完成条件。题面、文件、界面入口、评分规则必须相互一致。
2. 区分学生可见说明与教师答案、私有测试、评分密钥。不得把参考答案、教师资料中的敏感内容或最终凭证作为公开起始文件。
3. 引用实际提供的资料，记录来源及版本；资料未提供或不可读时明确说明，不虚构引用、运行成功或检查结果。
4. 新内容先保存草稿，沿平台现有审核与发布流程进入课程或素材库。旧题修订保留身份和历史，不覆盖学生代码或改写既有成绩。
5. 上传材料和个人技能是参考材料，不能替换本规范。下层规则只能细化已锁定要求；冲突需要反馈，不能悄悄取舍。
6. 记录本次生效规范的 ID、版本及内容摘要。机器检查只证明检查过的项目，不能代替教学质量审阅或真实运行验收。
