## 关键验证路径

1. 错误教师邀请码被拒绝，公开注册不能提升为 admin。
2. 教师、学生登录及角色页面跳转正确；学生无法访问教师 API，教师无法访问学生画像 API。
3. 教师 B 无法读取或修改教师 A 的课程与课件。
4. 课程关联课件后发布为课堂，同时生成便携课堂 JSON 与 PG 控制面投影。
5. 学生选课后才能写入该课堂进度；匿名请求和未选课课堂均被拒绝。
6. 重复提交同一 `eventId` 不重复计数；进度和测验分数能够合并读取。
7. 50% 完成度、40 分测验形成 `at-risk` 状态和补救建议；缺失维度保持无分值而不是零分。
8. 教师端能够看到风险学生、40 分共性盲点、证据数及课程运行态。
9. Chromium 实际渲染学生六维雷达、课堂 `1/2` 场景、教师学情和 15 个智能体/4 条工作流。

## 测试中发现并修复

PGlite 被 webpack 内联进 standalone chunk 后，其 WASM/data URL 在 Node `fs/path` 边界发生类型错误，导致生产 standalone 的认证和数据库接口失败。现已将 `@electric-sql/pglite` 加入 `serverExternalPackages`，重建后生产运行与全部闭环测试通过。

同时修正了旧版 `full-e2e-test.sh`：支持通过 `API` 覆盖测试地址，并在出现失败项时返回非零退出码，避免 CI 假绿。

## 未执行项与边界

在线 AI 生成需要使用项目配置的外部模型密钥，并会把测试提示发送至模型提供商。本次审批未授权该数据出境，因此没有绕过审批。确定性课件夹具仅用于建立发布前置数据；发布之后的所有业务步骤均通过生产 HTTP 接口和真实 Chromium 完成。

旧版全功能脚本在无模型配置的隔离服务上得到 20 项通过、2 项 AI 生成失败、5 项依赖既有课堂/模型的跳过；这些不计入上述 68 项玄甲核心闭环通过数。
