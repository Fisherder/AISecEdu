🔍 CAN总线概述

CAN（Controller Area Network）是汽车内部电子控制单元（ECU）之间通信的主流协议。所有ECU共享同一广播总线——任何节点发送的消息都会被总线上所有其他节点接收。

⚠️ 核心漏洞： CAN协议没有内置认证机制、没有加密、没有发送方身份验证。任何能接触到总线（如通过OBD-II端口、信息娱乐系统漏洞、或无线攻击面）的攻击者都可以注入任意CAN帧，而接收ECU会无条件信任并执行。

📋 Arbitration ID 与优先级

每条CAN消息以Arbitration ID（11位或29位）开头。ID不仅标识消息类型，还决定总线仲裁优先级——ID值越小，优先级越高。攻击者可利用低ID值抢占总线，淹没合法消息。

🎯 攻击场景

  • 仪表盘欺骗：注入伪造的速度/转速数据，使驾驶员看到虚假读数
  • 门锁控制：发送解锁命令，绕过安全系统
  • 拒绝服务：以极高频率发送高优先级（低ID）帧，阻塞合法通信
  • 安全功能禁用：抑制安全气囊、ABS等关键消息
🛡️ 防御措施：
  • CAN ID白名单：ECU仅接受预设ID范围的消息
  • 消息认证码（MAC）：在数据帧中附加加密签名
  • 入侵检测系统（IDS）：监控总线异常流量模式
  • 网络分段：使用网关隔离关键系统（动力总成 vs 信息娱乐）
  • 安全车载通信（SecOC）：AUTOSAR标准中的安全通信模块

📊 相关标准与框架

ISO 11898 — CAN协议标准  |  AUTOSAR SecOC — 安全车载通信  |  UN R155 — 汽车网络安全法规
