漏洞根因：ADS-B（1090 MHz Extended Squitter）是明文广播协议，设计之初未考虑安全威胁。任何拥有SDR（软件定义无线电）的人都可以在1090MHz频率上发送任意ADS-B帧，接收方无法区分合法与伪造信号。

攻击路径：

  1. 攻击者使用廉价SDR（如RTL-SDR，$20）监听1090MHz
  2. 构造虚假的位置帧，注入伪造的ICAO代码和坐标
  3. 持续广播 → 雷达屏幕出现"幽灵航班"
  4. 幽灵航班逼近真实航班 → 触发TCAS碰撞告警
  5. 可能导致飞行员采取规避动作，造成混乱

真实案例参考：

  • 2023年中东地区多次出现GPS/ADS-B欺骗事件
  • Flightradar24等公开平台曾显示不存在的航班
  • 乌克兰冲突区域频繁出现ADS-B干扰

防御措施：

  • 🔐 ADS-B认证（尚在标准化中，未广泛部署）
  • 📡 多点定位（MLAT） — 通过多个接收站交叉验证位置
  • 📶 信号方向探测 — 检测异常信号来源方向
  • 🧠 物理异常检测 — 检测不符合飞行物理规律的运动
  • 🛰 一次雷达交叉验证 — 与主动雷达回波对比
