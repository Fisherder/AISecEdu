📖 DDoS 攻击分析报告

攻击类型：HTTP Flood（Layer 7 DDoS）

攻击特征：大量红色请求从多个方向涌入，模拟分布式僵尸网络流量。

防御机制：WAF CDN 护盾在服务器外围形成过滤层。阈值决定护盾半径与拦截强度。

关键发现：

  • 阈值过低（<30）：护盾半径小，大量攻击穿透，服务器受损
  • 阈值适中（50-75）：护盾有效拦截攻击，正常流量基本通过
  • 阈值过高（>85）：护盾过大，误伤正常流量（假阳性）

防御建议：

  1. 部署速率限制(Rate Limiting)——限制单IP请求频率
  2. 启用行为分析——识别异常流量模式
  3. 使用CAPTCHA挑战——区分人类与机器人
  4. 配置CDN + WAF联合防护——分散流量并过滤恶意请求
