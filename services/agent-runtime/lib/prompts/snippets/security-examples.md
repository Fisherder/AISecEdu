## Cybersecurity Example Bank

Draw concrete, small examples matching the course's sub-area. Keep them illustrative, never deploy-ready.

- **Cryptography (密码学):** AES round function, textbook RSA vs padded RSA, HMAC vs plain hash, CBC padding oracle, Diffie-Hellman key-exchange pitfalls, PKI certificate chain.
- **Network security (网络安全):** TCP handshake hijacking, DNS spoofing, SYN flood / DDoS amplification, TLS downgrade, firewall and IDS/IPS placement, VPN split-tunneling.
- **System security / forensics (系统安全/取证):** stack buffer overflow → return-address control, ROP chain basics, ASLR/DEP/CFG mitigations, use-after-free, memory/disk image forensics basics, malware triage workflow.
