🔍 攻击概述

这是一次典型的 BLE Just Works 配对中间人攻击。攻击者利用 BLE 广告包的开放性，伪造了一个与目标智能锁同名的设备，并通过更强的信号诱导受害者手机连接到伪装设备。由于 SmartLock Pro 使用 Just Works 配对模式（无 MITM 保护），攻击者可以中继所有配对数据，获取短期密钥（STK）和长期密钥（LTK）。

⚡ 攻击链

  1. 侦察：攻击者扫描 BLE 广告，发现 00:1A:7D:DA:71:13 广播 "SmartLock Pro"
  2. 伪装：攻击者使用 28:FF:3C:B2:91:55 广播相同名称，信号更强（-42 dBm vs -45 dBm）
  3. 诱导连接：受害者手机连接到信号更强的伪装设备
  4. 中继配对：攻击者同时与真实锁建立连接，中继 SMP 配对数据包
  5. 密钥获取：Just Works 无 MITM 保护 → 攻击者获取 STK → 解密 LTK
  6. 未授权开锁：攻击者使用 LTK 加密发送 GATT 开锁指令

🛡️ 防御措施

  • 使用 Passkey Entry 或 Numeric Comparison 替代 Just Works
  • 启用 LE Secure Connections（使用 ECDH 密钥交换）
  • 在锁端实施 连接信号强度异常检测
  • 使用 OOB（带外）认证（如 NFC 触碰配对）
