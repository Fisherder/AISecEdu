📚 本实验使用的代码保护技术

            
    
                
  • 变量重命名：使用 _0x1a2b、_0x3c4d 等无意义名称替代语义化变量名。
    • 
                
  • 常量编码：数值常量通过表达式计算（如 (0x19 ^ 0x1a) + (0x0c >> 0x01) - 0x03 实际等于 3）。
    • 
                
  • 字符串拆解：目标字符串的字符编码存储在数组中，运行时动态还原。
    • 
                
  • 死代码注入：插入永不执行的分支（如 if (![])），干扰静态分析。
    • 
                
  • 布尔混淆：使用 !![] 表示 true，![] 表示 false。
    • 
            


            
🛡️ 更强大的防护策略（商业软件）

            
    
                
  • 服务端校验：将核心验证逻辑放在服务器端，客户端仅传递凭证。
    • 
                
  • 非对称加密签名：使用 RSA/ECDSA 对许可证进行数字签名，客户端用公钥验证。
    • 
                
  • 硬件绑定：将许可证与设备指纹（MAC地址、硬盘序列号等）绑定。
    • 
                
  • 代码虚拟化：将关键逻辑编译为自定义字节码，在虚拟机中执行（如 VMProtect）。
    • 
                
  • 反调试检测：检测调试器附着、检测代码完整性、计时检查等。
    • 
            

            

                ⚠️ 注意：任何纯客户端保护最终都可被逆向。安全不应依赖混淆，但混淆可提高逆向成本。
