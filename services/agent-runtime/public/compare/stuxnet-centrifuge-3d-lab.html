漏洞利用链：

1. 初始入侵 → USB/网络传播 2. 识别西门子 S7 PLC 3. 篡改 MW104 (最大转速限制) 从 1500→5000 4. 旁路 MW106 (安全联锁) → BYPASSED 5. 注入 MW100 (转速设定) → 5000 RPM 6. 劫持 HMI 显示 → 持续显示正常值 7. 物理破坏 → 离心机超速解体
