任务简报

2017年，Mathy Vanhoef 发现 WPA2 协议存在严重漏洞——KRACK（Key Reinstallation Attack，密钥重装攻击）。攻击者通过重放4次握手的消息3，迫使客户端重新安装已在使用的PTK密钥，导致nonce计数器重置。这将造成密钥流重用，从而可解密WiFi流量。你的任务：观察正常握手、执行重放攻击、观察后果、并编写修复方案。

漏洞名称：KRACK (Key Reinstallation Attack) — CVE-2017-13077 等系列

根因：WPA2 4次握手协议未强制要求客户端检测PTK是否已安装。当攻击者重传消息3时，客户端重新安装PTK并将发送nonce（数据包编号）重置为0，导致使用相同密钥和相同nonce加密不同数据——密钥流重用。

攻击链：

  1. 攻击者建立伪造的恶意AP（同SSID，同MAC）或在真实AP附近进行信道中间人
  2. 捕获真实的4次握手消息3
  3. 阻塞消息4使其无法到达真实AP
  4. 重放消息3给客户端 → 客户端重新安装PTK → nonce重置
  5. 捕获客户端使用重置后nonce发送的加密帧 → 密钥流重用 → 可解密

修复方案：客户端在安装PTK时应检查该密钥是否已被安装。若已安装，则不应重置nonce计数器，仅重新发送消息4作为确认。Linux的wpa_supplicant、Windows、macOS等均在2017年10月发布了补丁。

参考：Mathy Vanhoef, "Key Reinstallation Attacks: Forcing Nonce Reuse in WPA2", CCS 2017.
