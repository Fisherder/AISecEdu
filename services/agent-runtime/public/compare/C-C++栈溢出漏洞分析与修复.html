漏洞根因

strcpy() 不执行边界检查。它将源字符串的所有字节（直到null终止符）复制到目标缓冲区，完全忽略目标缓冲区的大小。当源字符串长度 ≥ 64 字节时，写入会超出 buffer[64] 的边界，覆盖相邻栈帧数据。

利用链

用户输入 → strcpy(buffer, user_input) → 覆盖 saved RBP（8字节）→ 覆盖返回地址（8字节）→ 函数返回时跳转到攻击者控制的地址 → 任意代码执行

修复方案

使用 strncpy(buffer, user_input, sizeof(buffer)); 并确保null终止，或使用 snprintf(buffer, sizeof(buffer), "%s", user_input);

防御层次

Stack Canary（编译时）→ ASLR（运行时）→ DEP/NX（硬件/OS）— 纵深防御
