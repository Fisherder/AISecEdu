防御配置：802.1X / EAP-TLS 证书认证

选择正确的防御方案来阻止 Evil Twin 攻击。点击正确的选项：

WPA2-PSK — 预共享密钥（密码认证）
客户端信任任何知道密码的AP
Open Network — 开放网络（无认证）
任何设备均可连接，无安全保护
802.1X + EAP-TLS — 基于证书的相互认证
✓ 服务器证书验证网络身份 ✓ 客户端证书验证用户身份 ✓ 防Evil Twin
MAC地址过滤 — 白名单控制
MAC地址可被嗅探和伪造，安全性低
