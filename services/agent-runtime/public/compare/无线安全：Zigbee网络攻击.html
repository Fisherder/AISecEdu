🛡️ Zigbee 3.0 密钥轮换防御

攻击成功后，学习Zigbee 3.0如何通过安装码（Install Code）和密钥轮换来防止此类攻击。

⚠️ 漏洞根因：使用了公开默认的信任中心链路密钥 ZigBeeAlliance09，攻击者可伪造协调器命令。
✅ 防御已激活：每个设备使用唯一的安装码派生密钥。网络密钥已轮换。攻击面已消除。
📖 Zigbee 3.0 安全机制说明

1. 安装码 (Install Code)：每个设备在制造时预置唯一的128位安装码 + 16位CRC，在加入网络时用于派生唯一的链路密钥。

2. 密钥派生：使用MMO哈希从安装码派生信任中心链路密钥，取代公开默认密钥。

3. 网络密钥轮换：协调器定期广播新的网络密钥，使用各设备唯一的链路密钥加密传输。

4. 帧计数器：防止重放攻击，每个设备维护传入/传出帧计数器。

🔗 参考：Zigbee Alliance Document 05-3474-21 (Zigbee 3.0 Security)
