🔍 攻击链分析

1. 被动嗅探：攻击者使用 Proxmark3 等设备在受害者刷卡时被动捕获电磁信号。对于 EM410x 卡（125kHz），卡片持续广播其 UID，无需任何认证即可读取。信号采用曼彻斯特编码，解调后直接获得明文 UID。

2. 信号解码：捕获的基带信号经曼彻斯特解码后，提取出卡片的唯一标识符（UID）。EM410x 协议没有任何加密层，UID 以明文形式传输。

3. 克隆写入：将提取的 UID 写入空白 T5577 或兼容芯片卡。T5577 是可编程的 125kHz 标签，可模拟任意 EM410x UID。写入过程仅需数秒。

4. 门禁突破：使用克隆卡靠近读卡器，读卡器将其识别为合法卡片并开锁。由于 EM410x 无挑战-响应机制，读卡器无法区分原始卡与克隆卡。

🧬 根本原因

EM410x 协议设计于安全性尚未成为首要考虑的时代。它仅提供静态 UID 广播，缺乏以下关键安全机制：

  • 无加密：UID 以明文传输，任何具备射频嗅探能力的人都能截获。
  • 无认证：读卡器不验证卡片真实性，卡片也不验证读卡器。
  • 无防重放：相同的 UID 每次都产生相同的信号，克隆卡与原始卡在射频层面完全不可区分。

🛡️ 防御方案

1. 双向认证 (Mutual Authentication)：MIFARE DESFire EV2 等现代卡片使用 AES-128 加密的挑战-响应协议。读卡器发送随机数（nonce），卡片使用内部密钥加密后返回。没有密钥的攻击者无法计算出正确响应。

2. 滚动码 (Rolling Codes)：每次认证成功后更新内部计数器或密钥，使得即使某次通信被截获，重放攻击也无法成功。常用于汽车无钥匙进入系统。

3. 多样化密钥：每张卡使用唯一的密钥（由主密钥和 UID 派生），即使一张卡被破解也不影响其他卡片。

4. 物理防护：使用屏蔽卡套防止被动嗅探，在不使用时将卡片置于 RFID 屏蔽环境中。

5. 多因素认证：将 RFID 卡与 PIN 码、生物识别或其他因素结合使用。
