🔍 漏洞根因

EM410x协议设计于1990年代，采用明文UID广播机制。卡片进入读卡器磁场后，持续循环发送64位数据帧（包含40位UID），无任何身份验证或加密。任何具备125kHz接收能力的设备（如Proxmark3）均可被动嗅探并复制UID。

⚔️ 攻击链

  1. 侦察：使用lf em410x reader在近距离读取目标卡UID
  2. 嗅探：使用lf em410x sniff捕获完整Manchester编码波形
  3. 解码：从波形中提取64位数据帧，解析出40位UID
  4. 克隆：使用lf em410x clone <UID>将UID写入可编程T55x7标签
  5. 利用：将克隆卡靠近读卡器，门禁系统无法区分原卡与克隆卡

🛡️ 修复方案

升级至MIFARE DESFire EV3（或同等级安全芯片），利用其3步双向认证机制：读卡器与卡片各自生成随机数，使用预共享密钥(AES-128)加密交换，双方验证对方确实持有正确密钥后才建立会话。即使攻击者嗅探到通信，也无法导出密钥或伪造响应。

📚 真实案例参考

2023年DEF CON演示中，安全研究员使用Proxmark3在0.3秒内克隆了一张办公楼EM410x门禁卡。同类攻击在物理渗透测试中成功率接近100%（针对未升级的125kHz系统）。MIFARE DESFire EV3目前尚无已知的实用克隆攻击。
