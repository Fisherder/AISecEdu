## 完整入口发现并修复的问题

- 审计写入使用的内部连接被对端关闭时，只重送同一事件并读取确认回执，接收端按哈希去重，保留原有审计要求。
- 方案审校直接输出审校结果，避免先耗尽推理预算再因截断重试。需求确认与发布审批协议保持原样。
- 脚本创建 SVG 的正常主图改为在真实浏览器渲染后检查；没有可见主图的页面仍会被拒绝。
- 浏览器检查明确报告重复点击处理导致的跳步，生成要求限定一种事件绑定方式；不能以放宽状态检查接受错误页面。
- 安全边界中提及真实 RSA 需要 OAEP，不再误判为要实现 OAEP 编码；实际要求 RSA-OAEP 或 OAEP 编码、计算、加解密仍走原有路径。

失败底稿、调用预算和任务记录均保留，没有清空旧任务的预算来绕过上限。
