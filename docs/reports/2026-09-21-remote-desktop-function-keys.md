# 远程桌面不支持功能键：文案修正（2026-09-21）

## 问题

题面、客户机内 README 和解题过程 PDF 里的操作步骤写的是「按 F3 打开文件」「按 F9 运行」「按 F12 暂停」
「Ctrl+G 跳转地址」「空格汇编」。实际使用中这些按键**传不到远程桌面**：浏览器会先截住它们
（F3 页面查找、F5 刷新、F11 全屏、F12 开发者工具、Ctrl+G 页面搜索），学生按了没有反应。

## 处理

所有步骤改为**纯鼠标路径**，并且菜单名称取自客户机里实际安装的 OllyDbg 1.10 中文版
（从 `Ollydbg.exe` 的字符串资源中核对，避免写出不存在的菜单项）：

| 要做的事 | 键盘（可能被浏览器占用） | 现在写的鼠标路径 |
| --- | --- | --- |
| 打开文件 | F3 | 文件 → 打开新的可执行文件（或把 exe 拖进窗口） |
| 运行 | F9 | 调试 → 运行程序 |
| 暂停 | F12 | 调试 → 暂停执行 |
| 单步 | F7 / F8 | 调试 → 单步步入 / 单步步过 |
| 跳到指定地址 | Ctrl+G | 在反汇编窗口右键 → 转到表达式 |
| 改指令 / 改字节 | 空格（汇编） | 在该行右键 → 二进制 → 编辑 |
| 下断点 | F2 | 在该行右键 → 断点 |
| 保存修改 | — | 右键 → 复制到可执行文件 → 所有修改 → 全部复制 → 副本窗口右键 → 保存文件 |
| 关闭被调试程序 | Alt+F2 | 调试 → 关闭程序 |

核对依据：`ollydbg.exe` 中确认存在「打开新的可执行文件 (F3)」「运行程序 (F9)」「暂停执行 (F12)」
「单步步入 (F7)」「单步步过 (F8)」「关闭程序 (Alt+F2)」「转到表达式(&G)」「二进制」「复制到可执行文件」
「所有修改」「保存文件」等字符串。

同时补了一条显式提示：远程桌面里功能键会被浏览器截住，请用菜单与右键路径。
