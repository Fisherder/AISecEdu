# 10.92 三维显示与操作问题诊断（2026-09-12）

## 用户实际页面

## 已查明原因

1. 用户实际 Microsoft Edge 的“在可用时使用图形加速”开关为关闭。`edge://gpu` 显示 WebGL Disabled、OpenGL Disabled，GPU 进程不可用的原因是浏览器设置禁止 GPU 访问。机器为 Apple M4，GPU 页面列出了 Metal 适配器；不是未发现显卡。
2. 原播放器在没有 WebGL 时用二维椭圆代替所有模型，但三维控制仍呈现为可用，未清楚说明能力差异。因此与另一浏览器三维截图明显不同。
3. 原三维模式下，默认导演镜头会阻止直接拖动和滚轮操作，必须先切换自由探索。新行为为直接拖动/滚轮时暂停并冻结当前镜头，再进入自由探索。
4. 原作品内嵌旧版播放器。只更新生成模板不会修复已保存的作品；新版预览从作品中验证、提取 SceneIR 后，用当前可信播放器重新编译显示，不修改数据库或历史版本。
