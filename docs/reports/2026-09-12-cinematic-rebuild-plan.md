# 演示生成重构：工作计划

目标：从能运行的简单拓扑，升级为具备精细场景、镜头编排、同步讲解和探索交互的高质量教学演示；生成至少三个明显不同的真实示例，在 10.92.35.7 项目中可打开。

## 已确认的差距

- 当前动画只有一次完整 HTML 模型调用；缺少可验证的分镜与场景合同。
- 原 OpenMAIC 导入版为 0.3.1 的本地分支；部分 `visualization3d-config` 提示明确要求伪三维卡片，不适合作为目标效果。
- 教师预览固定 400/500px，演示区域、讲解和操作被裁在滚动容器中。
- 旧验收主要证明控件能工作，没有证明构图、对象细节、镜头和叙事质量。

## 重构范围

1. 教学导演：从需求/原作品生成明确的教学目标、实体、连续分镜与视觉设计。
2. 结构化场景图：通用几何体、层级模型、连接路径、时间轨道、镜头关键帧、章节与标注；保存可编辑描述而非仅保存代码。
3. 可复用精细资产与电影感渲染：材质、灯光、阴影、环境、发光、细节实例和镜头；所有内容离线运行。
4. 播放器：大画幅、章节导航、播放/暂停/单步/时间轴、相机探索、模型拆解、画质设置；移动端及 WebGL 缺失可用。
5. 生成/修订/旧作品兼容：保持项目合集、权限、版本与原课件；继续使用已配置的 Flash 模型。
6. 质量门禁：结构验证、真实浏览器截图与运行错误、实际场景几何/镜头变化、教学语义与视觉人工检查；不是只有绿灯计数。
7. 至少三个主题示例，并验证再次生成和自然语言修订走同一条生产流程。
