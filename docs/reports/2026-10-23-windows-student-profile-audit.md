## 已部署的关机保护

先前修复已补上注册表和磁盘刷新，以及 Windows 正常关机请求。本轮继续修复了关机失败后仍可能强制清理的路径。

1. **确认关机结果。** 同时检查 QEMU 进程和控制通道。虚拟机仍在运行且控制通道失联时，返回未完成关机；不会把连接错误当作关机成功。单次确认命令有 45 秒上限。
2. **手动停止和切换环境。** Windows 尚未确认关机时，保留容器与个人磁盘。停止接口返回 HTTP 409 和可读提示，用户稍后可重试。
3. **保留正确的实验状态。** 实际移除成功后，才写入停止证据并将实验标记为 STOPPED；关机未完成时继续保留 ACTIVE 状态。
4. **定时和容量清理。** Windows 关机失败、超时或调用异常时跳过删除，并在服务日志记录保留原因。同一轮清理不重复处理同一容器。其他运行环境保持原回收行为。

部署文件为 `dojo_plugin/agent_runtime/guest_input.py`、`dojo_plugin/api/v1/docker.py` 和 `watchdog/docker_remove_containers.py`。更新前逐一校验旧文件摘要并保存备份；应用服务已重新加载，运行中的清理脚本已替换。

持久化清理镜像为 `pwncollege-watchdog:profile-safe-stop-20261023`，并更新 `pwncollege-watchdog:latest`。镜像 SHA-256 为 `3f724bd6e3fed1627bafacc532bcda56a26e53078ef65ea6ac8ed6c02dd4e4c4`。这取代先前维护记录中的 `profile-fix-20261023`，作为本轮之后的清理版本。
