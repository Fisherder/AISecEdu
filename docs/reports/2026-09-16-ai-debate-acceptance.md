# AI 辩论上线与验收

日期：2026-09-16。正式站点：http://10.92.35.7:8080/ 。本次在既有产物基础上增加可由教师生成、发布的 AI 辩论。

## 使用入口

1. 教师打开 `/teacher`，选择「AI 辩论」，说明学生、情境和辩题；选择生成方案后得到可试练活动。
2. 教师可以用自然语言调整指定字段；确认内容后沿现有流程发布到课程章节。
3. 学生进入对应章节，点击「进入辩论」，选择立场并逐轮发言。完成反思后得到带具体发言引用的量规反馈。
4. 活动自动保存记录和草稿，可换立场练习、导出 Markdown 复盘。教师可在预览页选择「查看学生记录」。

## 已交付行为

- 结构化原生活动：辩题、场景、身份、正反立场、学习目标、3–6轮任务、资料、量规及反思提示。
- 学生与 AI 对练；对手响应完整历史，论证建议与最终学习评价分开生成。
- 结构校验和受限格式修复；资料引用、学生原话引用和评价引用均校验归属。
- 顶层字段补丁修改，未修改字段保留原值；已开始的对练固定活动版本，新对练使用最新版。
- 数据库存储、请求去重、并发控制、失败后重试和草稿恢复；服务端课程/章节/个人记录权限校验。
- 教师试练与学生记录分开；成功的对话调用计入模型使用记录，个人学习场景沿用额度检查。
- 适配当前 HTTP 站点：随机请求标识使用 `crypto.getRandomValues`，避免非安全上下文中 `crypto.randomUUID` 不可用导致提交卡住。
