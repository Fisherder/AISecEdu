# 移除建设任务系统

建设任务的中心页面、批次/成员/任务分配、领取、提交、复核、终审、验收入库和专用接口已删除。旧 `/teacher/construction`、`/pwncollege_api/v1/construction/*` 及对应静态文件返回 404，不再提供入口或登录跳转。

账号激活、课程教师身份判断、素材库、作品预览保留。教师身份来自现有课程关系或平台管理员身份；分配账号的首次密码设置由 `assigned_account_activations` 独立维护。素材库可以正常保存、共享、选用和预览。历史已保存的作品与文件保留，固定副本通过通用 `readOnly` 课程标记保护，已撤销的素材版本仍不能导入。`artifact_files.py` 仅保留旧文件格式的读取兼容，不注册任何任务功能。

## 已有环境升级

维护者先安排对应环境维护窗口，固定源码提交，备份数据库及作品文件，验证备份可恢复。停止该环境的 CTFd 和全部教学 Worker；不要将开发配置或数据库写入生产。

在新代码第一次启动前，用 PostgreSQL 客户端对目标库执行：

```sh
psql -v ON_ERROR_STOP=1 "$DATABASE_URL" -f db/migrations/20261118_retire_construction.sql
```

这里的 `DATABASE_URL` 为 PostgreSQL 客户端 URL，例如 `postgresql://...`，不是 SQLAlchemy 的 `postgresql+psycopg2://...`。凭据从目标环境的私有配置读取，不填写在共享文档或命令日志中。

迁移在单个事务中保留账号激活状态、历史副本只读标记和素材撤销状态，然后删除九张专用表及旧触发器。已移除旧表时可以重复执行；只有部分旧表存在时会拒绝并回滚。新安装不需要运行该迁移。迁移不会在应用导入时自动删除数据。

完成后启动新代码，通用只读保护会在 schema 初始化中安装。验收旧路径 404、账号密码激活、教师/学生权限、素材库及历史作品预览，核对课程、账号、素材和作品数量。测试 `test/test_construction_retirement.py` 在真实 CTFd 上下文运行，包含角色与历史素材访问边界。

回退必须同时恢复配套源码与数据库。不要只恢复旧源码，否则旧模块会重新创建空任务表并丢失原有状态。
