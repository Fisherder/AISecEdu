# 教学智能体图形化体验

教师登录后仍进入 `/teacher` 的统一工作台。首页突出 AI 教学智能体、教学任务输入和可操作案例；学生继续使用 `/guide`，权限与数据边界沿用现有系统。

## 需求对应

| 教学要求 | 实现与验收 |
| --- | --- |
| 登录后看到整体教学智能体 | 教师首页展示统一输入、已有课程与任务；不限定课程时可先讨论教学想法 |
| 图文并茂的工控、车辆案例 | 工控与车联网两种概念仿真，控制链、反馈链、过程对象和仪表同步显示 |
| 动态过程展示 | 六阶段播放、暂停、单步、阶段选择、全屏、参数调节、独立校验、过程记录与确定性重置 |
| 模型快速生成教学内容 | 预演将完整要求带入同一教学会话，继续使用模型规划、方案选择、正式生成、预览、编辑与发布流程 |
| 动态课件 | 首页提供六页带同步讲稿的案例预演，模型入口要求正式生成图文页面、动态演示与逐页讲稿 |
| 学生辩论 | 首页提供多立场、三轮交锋和试投票；正式 debate 产物保留辩论类型，进入课堂后加载主持人、正方、反方和事实核查四个模型角色，学生可发言参与 |
| 观察学情 | 首页读取受课程权限保护的课程进度与课堂参与接口，展示完成率、周活动、证据量、关注分布和真实课堂回应；可见时每 45 秒刷新 |

首页预演为明确标识的内置示例，不会创建学生、成绩、学习记录或课程。试投票仅存在当前页面。学情无学生、无作答或无必修题时分别显示空态或不可计算，不填充示例统计；课程切换与刷新使用请求序号，旧响应不能覆盖当前课程。

工控案例为震网启发的教学抽象，参考 [CISA 原始通告](https://www.cisa.gov/uscert/ics/advisories/ICSA-10-272-01)。变量与阶段均为概念示意；车联网场景为虚构教学情境。浏览器播放器不访问目标设备、不执行载荷。

## 定向验证

`node --test test/test_teaching_showcase.cjs` 验证两种情境的反馈失真、参数作用、校验分支、恢复、暂停、重复执行、边界约束和重置。

界面验收覆盖桌面与 320–768px 窄屏、阶段跳转、键盘页签、播放暂停、双次重置、减少动效、文字对比度、课件讲稿、辩论轮次、生成入口和真实课程图表。模型验收使用新实例配置的模型，验证 simulation、slide-deck、debate 真实产物及课堂链路。


## 正式生成与课堂

教师选择课程后，继续通过统一智能体完成三种方案规划、方案选择、正式生成、修订、预览和发布。工控/车辆仿真使用同一套原生渲染流程：模型提供目标、内容与讲授提示，领域渲染器将它们编译成工程站、控制器、物理过程与监视反馈同步的可操作场景。SQL 场景继续使用其原有渲染器。

仿真包含六阶段、偏差参数、独立校验、过程与显示值对照、事件记录、单步、播放暂停和重置。正式课件保留逐页讲稿、内容目录、全屏和学生视图。中文文本采用系统中文字体回退并允许自然换行，避免浅色背景配浅色字或中文长行溢出。

教师在产物页点击“开始课堂”，复用当前版本的有效课堂或创建该版本课堂。学情面板显示可分享的课程课堂入口，支持复制链接和结束课堂；学生必须已经加入课程。入口会签发一次性运行时票据，分享链接本身不含票据。结束后的课堂保留为课后回顾。

课堂直接使用平台配置的模型，浏览器只获得模型名称，密钥和服务连接配置保留在服务端。独立版管理接口继续关闭。`/avatars`、`/logos`、`/vendor` 的兼容跳转使用相对位置，保留部署端口；Nginx 配置显式挂载，重建容器后仍然有效。

## 学情口径

课程完成率仍依赖现有已验证结果。新增课堂参与统计取近 28 天当前课程成员的加入、发言/参数比较、阶段决策与活动完成记录；不将 AI 角色、教师预览或首页试投票计入学生参与，不将课堂互动自动转换为成绩。无数据时显示真实零值或不可计算状态。

浏览器事件经现有认证桥接提交。后端检查课程、章节、成员、场景与事件类型，按学生和客户端事件键去重。网络失败会排队重试并显示状态；学生不能读取教师学情。课程切换时，旧请求不能覆盖新课程图表。
