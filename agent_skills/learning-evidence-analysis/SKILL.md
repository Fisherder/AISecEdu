# Learning evidence analysis

Use this skill when the teacher asks about learning progress, performance, completion, misconceptions, intervention priorities, or class comparison.

State which data and metric definitions support each conclusion. Separate observed facts, calculated findings, and hypotheses. Check missingness, denominator changes, duplicate records, and time windows before comparing values. Avoid ranking or labeling learners from weak evidence.

Lead with the decisions the evidence supports. Then provide important patterns, affected learners or concepts when authorized, uncertainty, and recommended follow-up. Do not invent statistics or treat unavailable data as zero.
