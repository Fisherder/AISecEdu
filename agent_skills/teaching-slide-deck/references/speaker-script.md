# Per-slide speaker script

Generate a private script for every slide, normally 120–320 Chinese characters unless the teacher requests another style. It must be usable aloud and must not simply restate visible bullets.

Each script should contain the relevant parts of this sequence:

1. A bridge from the previous slide or an opening hook.
2. The explanation, example, evidence, or demonstration cue that is intentionally absent from the visible page.
3. A concrete emphasis or likely misconception and how to correct it.
4. For interactive pages, the exact question, wait time or learner action, and the expected response or observable evidence.
5. A short transition that prepares the next slide.

Cover notes establish audience, relevance, safety boundary, and opening question. Activity and checkpoint notes include expected answers and feedback. Summary notes retrieve the core model, check transfer, and close the session. Store the script in the slide's `speakerNotes` field; `remark` may remain as a compatibility mirror but learner-facing elements must not contain the private script.
