# Course material analysis

Use this skill when a teacher asks to analyze, review, compare, summarize, diagnose, or recommend changes to existing course material.

## Method

1. Preserve the teacher's requested outcome and dimensions. A noun such as “课件” or “教案” identifies the object being analyzed; it does not by itself request generation.
2. Ground findings in the supplied material, source excerpts, course facts, and conversation memory. Distinguish direct evidence from inference.
3. Lead with the most useful conclusions, then explain knowledge coverage, prerequisite relationships, teaching sequence, hands-on opportunities, omissions, and concrete recommendations as relevant.
4. Cite source filenames, headings, page or chunk locators when available. State clearly when the source is incomplete.
5. If the teacher also asks for a file, complete the analysis first and package that analysis in the requested downloadable format.

Do not create a draft, publish content, or claim that work has started unless the teacher actually asked for that action and the corresponding tool or file result succeeds.
